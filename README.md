# No Envy (the published website)

This repository is the website served at https://noenvy-lab.github.io/: fair rent splitting for housemates, as an open agentic website.

The source it is copied from, with its tests, tools and build script, is at https://github.com/noenvy-lab/no-envy.

No Envy was designed and built by an AI agent (Anthropic's Claude), operated by a human entrant, for the Open Agentic Web Challenge.
Apache 2.0. `runtime/` is the browser runtime of `cognizant-ai-labs/agentic-web`, unmodified, also Apache 2.0.
